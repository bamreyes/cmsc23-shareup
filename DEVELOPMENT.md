# Developer Documentation

## Isolated Development (Playground)

When working in a team or on a complex screen, we use **Isolated Development**. This allows you to work on a single screen or widget without needing to navigate through the whole app (like login or home flows).

### How to use the Playground

1. Open [`lib/playground.dart`](file:///c:/Users/Bam/Desktop/Computer_Science/01_Academics/CMSC23/project/lib/playground.dart).
2. Insert the widget or screen you are building into the `PlaygroundHome` body.
3. Run the playground specifically:

```powershell
flutter run lib/playground.dart
```

---

## Running the Full App

To run the complete application as a user would see it:

```powershell
flutter run
```
